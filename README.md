# Yes or No

A simple interactive website built with HTML, CSS, and JavaScript. Features a funny question, a moving "No" button, and a cute message when "Yes" is clicked.

## Features

* Interactive Yes and No buttons
* Moving "No" button
* Heart animations ❤️
* Sound effect
* Simple dark theme with pink glowing effects

## Built With

* HTML
* CSS
* JavaScript

## Purpose

A fun little project to practice web development.
